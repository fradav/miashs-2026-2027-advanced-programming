# Advanced Programming and Parallel Computing — M2 MIASHS

Quarto book support for the module "Advanced Programming and Parallel Computing",
M2 MIASHS, 2026–2027.

- **Teaching design**: self-directed, co-constructed learning with two tracks
  (Socratic AI tutor and classic learning) and reciprocal observation.
- **Technical content**: asyncio, IPC and locks, distributed computing (Dask/Ray), SIMD,
  GPU, WebGPU.
- **License**: CC BY-NC-SA 4.0.

## Build the site

```sh
quarto render
```

The site is generated in `docs/` and published via GitHub Pages:
