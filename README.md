# Programmation avancée et calcul parallèle — M2 MIASHS

Support de cours (site Quarto book) du module « Programmation avancée et calcul parallèle »,
M2 MIASHS, 2026–2027.

- **Dispositif pédagogique** : apprentissage autonome co-construit, avec deux parcours
  (tuteur IA socratique et apprentissage classique) et observation croisée.
- **Contenu technique** : asyncio, IPC et verrous, calcul distribué (Dask/Ray), SIMD,
  GPU, WebGPU.
- **Licence** : CC BY-NC-SA 4.0.

```sh
quarto render
```
